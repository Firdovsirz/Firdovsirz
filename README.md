## About

I lead and build full end-to-end systems in production at **Azerbaijan Technical University** and **Dithari** — owning everything from database architecture and backend services to frontend interfaces and deployment. My focus is distributed systems, education technology, and research infrastructure: software that has to be reliable, fair, and maintainable because real institutions depend on it daily.

- 🏗️ I design systems end-to-end — data model, services, API, UI, and the infrastructure they run on
- 🤖 I build LLM-backed systems that are auditable and trustworthy, not just demos
- ⚙️ I care about the parts that don't show up in screenshots: validation, observability, and the pipeline around the feature
- 👥 I lead teams and make architecture decisions that have to hold up over time

## Featured Work

**🎓 [Azerbaijan Technical University — Official Platform](https://aztu.edu.az)**
Full-stack developer on the university's official web platform serving 10,000+ students. Bilingual (AZ/EN), server-rendered, with an integrated AZ/EN AI assistant.
`Next.js` · `TypeScript` · `FastAPI` · `PostgreSQL` · `Redis`

**📊 Plan-Report Information System — [Case Study](https://firdovsirzaev.online/blog/scoring-without-a-human-a-rubric-constrained-llm-pipeline-for-university-plan-reports)**
A rubric-constrained LLM pipeline that scores university plan-reports with no human in the scoring path — fair, repeatable, and fully auditable. Validated against human baselines before replacing them.
`FastAPI` · `React` · `Next.js` · `PostgreSQL` · `LLM pipeline`
